# Security Policy

## Supported Versions

We will provide security updates for the latest minor release of **PerSent**.  
Please upgrade to the latest version before reporting issues.

| Version | Supported          |
| ------- | ------------------ |
| latest  | ✅                  |
| older   | ❌                  |

## Reporting a Vulnerability

If you discover a security vulnerability in **PerSent**, please follow these steps:

1. **Do NOT open a public issue.**  
   Publicly disclosing a vulnerability before it is fixed can put users at risk.
2. Send a detailed report to:  
   📧 **RezaAsadiProgrammer@Gmail.com** (recommended)
3. Include:
   - The version of PerSent you are using.
   - Steps to reproduce the issue.
   - Any proof-of-concept code.
   - The potential impact.
4. Encrypt your report if possible (we can exchange PGP keys upon request).


>  After the fix is released, we may publicly credit you (if you agree).

Thank you for helping keep **PerSent** and its users safe 💛

> RezaGooner
